# 🏋️ FitBuddy — 练了没变化？先查原因

> 大多数计划一开始是有效的——问题是没人告诉你它**什么时候失效**。
>
> FitBuddy 按你的目标、水平、可用天数生成带渐进超负荷和减载周的周期化计划，然后盯着你的训练记录：卡在重量、容量、恢复还是频率，直接给结论。
>

## ✨ 为什么是 FitBuddy？

大多数健身 App 只是**把一堆动作扔给你**，然后按月收钱。

FitBuddy 不一样：

| 常见做法 | FitBuddy |
|---------|----------|
| 每月 ¥25~¥40 订阅费 | **核心功能永久免费**，MIT 开源 |
| 训练数据上传云端 | **100% 本地存储**，只有你能看到 |
| 随机动作堆砌成"计划" | **科学周期化**：适应 → 渐进超负荷 → 减载 → 再突破 |
| 一套计划应付所有人 | **5 目标 × 3 水平 × 自定义天数**，分化方案自动说明理由 |
| 练了三个月不知道有没有进步 | **卡点诊断**：按训练记录判断卡在重量/容量/恢复/频率 |
| 训练、饮食两张皮 | **计划与饮食计算器联动**，每个训练日单独定量 |

## 🎯 核心功能

### 📊 智能训练计划生成
- **5 大目标**：增肌 / 力量 / 减脂 / 心肺体能 / 马拉松（16 周备赛）
- **3 个水平**：新手 / 中级 / 进阶，自动调节训练量和休息时间
- **2-6 天/周**：灵活适配你的时间
- **多种设备**：健身房器械 / 哑铃 / 弹力带 / 自重
- **5 个快速模板**：新手 6 周 / 增肌 12 周 / 减脂塑形 / 居家徒手 / 马拉松新手
- **分化方案外显**：摘要卡直接说明用了什么分化（如上下分化）、为什么这么排

### 🔄 周期化训练逻辑（这是核心）
```
第 1 周  适应期   → 建立动作模式，中等强度
第 2-3 周 增负荷  → 渐进超负荷，推动肌肉/力量增长
第 4 周  减载周  → 降低训练量，防止过度训练
然后下一周期重新开始，重量/组数递增
```
这是力量训练教科书里的方法，99% 的健身 App 没做。

配套的执行保障：
- **周期化日历**：一眼看清当前处于适应/增负荷/减载哪个阶段
- **RPE 自动调整提示**：按自感强度给出升降重建议
- **疲劳预警**：连续高强度训练时提醒你主动恢复
- **漏练补练提醒**：错过训练日自动给出补练方案

### 🏃 马拉松专项
- 16 周分阶段备赛计划
- LSD（长距离慢跑）自动排程
- 配速计算器（全马/半马目标配速一算即得）
- 分档营养食谱和补给策略

### 🍎 饮食计算（计划联动）
- 基础代谢率 + TDEE 计算，三大营养素配比
- **与计划页营养建议联动**：饮食计算器直接采用计划算好的目标，一键同步
- **按训练日分档**：休息日、每个训练日按各自消耗量单独定量——LSD 大课日和轻松跑日的碳水目标可以差 140g，不再一刀切
- **今日已吃追踪**：对着当日目标记录摄入，百分比进度直观可见
- 增肌/减脂双套饮食指南（中国饮食习惯适配）

### 📈 进度追踪
- 训练量走势图表（Canvas 绘制，折叠卡展开自动重绘）
- PR 个人纪录卡：每个动作的最佳成绩自动归档
- 连续打卡记录 + 热力图

### 🏆 游戏化激励系统
- 4 类 17 枚成就徽章
- 6 级等级系统
- 里程碑庆祝动画
- 热量消耗换算食物等价物（12 种）

### 🔧 实用工具（动作库页）
- **1RM 极限重量计算**：Epley + Brzycki 双公式，百分比负荷表
- **热身组计算器**：按正式组重量自动排热身递增组
- **杠铃片计算器**：目标重量自动换算两侧挂片方案
- **组间休息计时器**：浮动按钮，5 档预设（30s/60s/90s/2min/3min），蜂鸣音效
- **动作库搜索**：86+ 动作示范 GIF，支持按名称筛选
- **数据备份**：JSON 导出/导入 + 备份码，换机不丢数据

### 📱 PWA 支持
- 可安装到手机主屏幕（iOS/Android），带安装引导横幅
- Service Worker 离线缓存
- 训练提醒通知
- 深色模式一键切换


```
├── data-constants.js    # 静态数据：动作库/配置/饮食指南

├── backup-code.js       # 备份码生成/恢复

├── analytics.js         # 访问统计（51.la）

├── exercise-images/     # 图标与打赏二维码
```

## 🐞 找 Bug · 公开测试

FitBuddy 是个人独立开发，**没有预算发红包**。所以奖励换成了另外两样东西：

只要你提交的 Bug 或建议**被采纳**：

- 🏆 名字**永久**挂进站内的[荣誉墙](https://santeb.github.io/fitbuddy/index.html#page-donate)
- 🎁 未来若推出任何付费功能（如云同步），你**终身免费**

**怎么提交**（挑最顺手的一个）：

| 方式 | 适合什么情况 |
|------|------------|
| 站内「发电」页 → 🐞 **提 Bug** | 推荐。会自动打包设备、浏览器、当前页面、计划配置和最近的报错，你只需写一句「发生了什么」 |
| [GitHub Issues](https://github.com/santeb/fitbuddy/issues) | 习惯在仓库里聊的，或者想贴截图、贴代码的 |
| 页面里的反馈弹窗 → 📧 发邮件 / 🤝 去群里说 | 不方便用 GitHub 的 |

**提什么最有用**：点了没反应、数字算错、页面错位、某个说法看不懂、某一步让你想放弃。
「我觉得这里可以更好」也算——**体验问题同样是 Bug**。

> 提了是真的会改。每修好一条，下面这行就会多一个名字。
