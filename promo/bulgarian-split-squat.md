# 保加利亚分腿蹲：练腿练臀最狠的动作，也最容易做废

只留一个练腿动作，我选保加利亚分腿蹲。单腿承重、重量减半刺激不减，还能顺手暴露左右腿的力量差。

代价是它也是最容易做废的——做完膝盖不舒服，基本都错在下面这几个设定上。

**① 后脚别搭太高**

凳面 30-40cm 就够，别超过膝盖高度。搭得越高髋屈越多、越像练臀，越高越蹲不下去。

**② 前脚站远一点**

最关键的参数。前脚离凳约一个半到两个脚掌，蹲到底时前膝大致在脚踝正上方。

站太近，前膝只能往前冲，压力全给膝盖——这是"做完膝盖疼"的第一原因。

**③ 后脚用脚背搭，不是脚尖踩**

脚背平搭在凳上，脚踝放松。用脚尖踩会把小腿绷紧，人下不去，只能假动作。

**④ 躯干略前倾，别驼背**

前倾 10-20 度，重心压在足中。想臀多一点就多前倾，想腿多一点就站直些。塌背一律是错的。

**⑤ 髋往后下方沉，不是往前扑**

髋找脚跟的方向走，后膝朝地面去。全程前脚掌三点（大脚趾、小脚趾、脚跟）踩实不走位。

**四个高频错误**

1. 前脚太近 → 前膝过脚尖、脚跟翘起，往后挪半个脚掌
2. 后脚搭太高 → 变成"跪着抬臀"，腿完全没感觉，换矮凳
3. 后腿蹬地帮忙 → 感觉两边都在发力就是错的，后腿只负责平衡
4. 弯腰低头看地 → 核心一松就晃，眼睛看前方一个固定点

**到底蹲多深**

前腿大腿接近水平、后膝离地 2-3cm 就停。再往下后膝顶地、骨盆会开始翻转，腰反而吃力。

**怎么练**

- 每条腿 3-4 组 × 8-12 个，组间休息 90-120 秒
- 从徒手开始，站稳了再拿哑铃，别一上来就上重量
- 左右差距大的，从弱的那条腿开始做，弱侧先练
- 平衡感差、膝盖有伤，先扶墙做，稳定之后再放开

不会排练腿日的，我做了个免费计划工具，组次和重量进阶都帮你算好，主页能找到。
