# 杠铃深蹲全拆解：蹲对全身受益，蹲错腰膝埋单

杠铃深蹲是力量训练的天花板，也是最容易做错的动作。从出杠到回杠拆成六步，每步讲清楚怎么做。

**① 设定杠位**

高杆位（压斜方肌上沿）适合大多数人。握距略宽于肩，肩胛收紧下沉，用背"架住"杠——手只锁不托。手腕疼的人，九成是用手扛杠。

**② 出杠**

起杠瞬间就收紧核心，退杠不超过三步。站距：脚跟与肩同宽，脚尖外展 15-30 度。

**③ 呼吸加压**

用瓦式呼吸：气吸进腹部，像准备挨一拳那样绷住核心，全程保持腹压，站直再换气。腹压是天然腰带，核心不收紧，戴再贵的腰带也没用。

**④ 下蹲**

髋膝同时启动，想象向后坐进椅子，膝盖全程对准脚尖，蹲到大腿与地面平行或略低。

硬标准：杠铃轨迹接近一条竖直线，全程压在脚掌正中上方。轨迹向前飘，就是重心跑到脚尖了，腰马上代偿。

**⑤ 底部与起身**

底部有控制地停一瞬，再全脚掌蹬地站起，胸口和髋一起上升。

起身最忌屁股先抬、躯干被压成"早安式"——这一下腰承受的全是剪切力。想着"肩先动"。

**⑥ 回杠**

杠铃碰到立柱、确认挂稳再松手。受伤不发生在最重那一下，很多发生在回杠松懈的那三秒。

**五个高频错误**

1. 用手扛杠 → 收肩胛，用背架杠
2. 膝盖内扣 → 想象两膝往外顶、把地面踩开（女生尤其常见）
3. 脚跟离地 → 脚跟垫小杠铃片，补脚踝活动度
4. 早臀起身 → 胸口和髋一起走
5. 借反弹弹起 → 每周练一次停顿式深蹲

**重量怎么加**

新手从空杆开始，每次加重不超过 2.5kg。深蹲放练腿日第一个动作：4-5 组 × 5-8 个，组间休息 2-3 分钟。
