| **传统硬拉全拆解** No.03 | 话题性强，"伤腰"恐惧=高互动（评论区会吵） | 中 | ★★★★ |

## 三、方向 B：避坑/反问类（小红书最容易爆的体裁）

标题带「别再」「真的会」「吗」的互动率普遍高。成本低，可以穿插发。

| 选题 | 钩子 |
|---|---|
| **局部减脂不存在** | 全民误解，评论区必吵 |
| **女生练力量会变壮吗** | 打消女性顾虑，涨女粉利器 |
| **出汗多≠消耗多** | 短平快，适合做图文 |
| **练后30分钟窗口是真的吗** | 辟谣 + 科普，专业感 |
| **有氧到底毁不毁肌肉** | 长期争议话题 |
| **只练手臂会怎样** | 用反例讲清复合动作价值 |
| **练腿会粗腿吗** | 女性向高频焦虑 |
| **空杆都推不动怎么办** | 新手共鸣，转化率高 |

## 四、方向 C：可直接照抄的计划类（引流最强）

这类是「收藏率之王」，也是导 App 最自然的钩子。

| 选题 | 形态 |
|---|---|
| **一份能直接抄的每周训练计划（新手版）** | 表格图，收藏爆款 |
| **每周练3天怎么排（上班族版）** | 时间少人群刚需 |
| **推拉腿怎么分** | 进阶向，专业度 |
| **组数次数到底怎么选（5×5 vs 3×10）** | 争议 + 方法论 |
| **组间休息到底多久** | 小切口，人人有疑问 |
| **不会加重量了怎么办** | 平台期痛点，导 App 顺 |
| **新手前3个月该怎么练** | 长尾流量稳定 |

## 五、方向 D：恢复与身体信号（信任感培养）

| 选题 | 钩子 |
|---|---|
| **关节疼 vs 肌肉酸，怎么区分** | 决定"该不该停"，实用 |
| **睡不够能不能练** | 打工人高频 |
| **酸痛还能不能继续练** | 新手最常见疑问 |
| **过度训练的4个信号** | 恐惧 + 自查 |

注意：已发过「酸痛」机制科普，此处要写「怎么办」而非「为什么」，避免重复。

## 六、方向 E：营养（流量最大，但风险也最大）

| 选题 | 风险提示 |
|---|---|
| 蛋白质到底吃多少 | 安全，建议做 |
| 补剂要不要买（蛋白粉/肌酸） | 安全，但别推荐品牌 |
| 减脂怎么吃不饿 | 安全，实用 |
| 空腹训练好不好 | 有争议，客观写 |
| 增肌要不要脏增 | 观点性，注意立场 |

**风险**：营养内容容易踩合规线（不能给医疗建议、不能承诺效果）。建议只做「原理 + 通用原则」，不给个体方案。

## 七、下一步建议（按优先级）

**第 1 优先：杠铃卧推拆解（No.02）**
- 系列连贯性是内容号的复利，断了就白攒
- GIF 生成脚本现成，改动作参数即可
- 深蹲那篇的封面模板直接复用改字

**第 2 优先：一份能照抄的每周计划（新手版）**
- 收藏率最高的体裁，直接导 App
- 和你产品的核心功能（周期化计划生成）天然咬合

**第 3 优先：局部减脂不存在（辟谣类）**
- 成本最低（纯文字 + 一张封面）
- 爆发力最强，适合在系列内容之间穿插涨粉

## 八、发布节奏建议

- **主线**：动作拆解系列（编号连续）——养"追更"习惯
- **穿插**：辟谣/反问类——拉新流量
