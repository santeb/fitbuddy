# 练后恢复，真正有用的只有2件事

练完怎么恢复？网上方法一大堆，但大多数是安慰剂。真正管用的只有两件事。

**一、睡够（占恢复的大头）**

肌肉不是在健身房长的，是在你睡着的时候长的。生长激素主要在深睡阶段分泌——睡眠不足，练得再狠也是白练。

标准：每天 7 小时以上，尽量固定作息。做不到的话，把训练量降下来，比硬顶着练强。

**二、吃够（练后别拖）**

恢复需要原料：热量 + 蛋白质。

- 蛋白质：每天每公斤体重 1.6-2.2g（70kg 约 110-150g）
- 练后 2 小时内吃一顿：碳水 + 蛋白，别只冲蛋白粉不吃饭
- 总热量不够，恢复一定慢——减脂期尤其明显

**三、这些方法被高估了**

- 静态拉伸 → 不减轻酸痛，它改善的是柔韧，不是恢复
- 泡沫轴 / 按摩枪 → 只让你暂时"感觉好"，不等于恢复更快
- 冰浴 → 可能抑制肌肉增长，新手不建议碰
- 恢复类补剂 → 证据薄弱，不如多睡一小时

它们不是没用，是别指望它们替代睡眠和吃。

**四、这些直接拖后腿**

练后喝酒、熬夜、连续两天把同一部位练到力竭。

**五、怎么判断恢复到位了**

- 同一部位间隔 48 小时再练，是最省心的标准
- 晨起心率比平时高 5-10 次/分 → 还没恢复，今天降强度
- 同样的重量感觉明显变沉、力量掉两成以上 → 先休息，别硬上

**一句话总结**

睡够 + 吃够 = 八成恢复，其余都是锦上添花。
