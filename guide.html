🏋️ FitBuddy 使用教程

免注册 · 免费 · 数据只存在你自己手机里。看完这篇大概 3 分钟。
⚡ 30 秒出计划
1
打开就点一个模板 首屏「⚡ 选一个，直接出计划」有 6 个：梨形塑形 / 新手 6 周 / 增肌 12 周 / 减脂塑形 / 居家徒手 / 马拉松新手。点一下，计划立刻生成，不用填任何表。
2
不满意再展开「🎯 手动调参数」 目标（增肌/力量/减脂/塑形/心肺/马拉松）、水平（新手/中级/进阶）、每周练几天、周期长度、器械（健身房/哑铃/徒手/弹力带）、伤病限制、身高体重年龄。改完点「✨ 生成我的计划」。
3
照着练，练完打勾 每天的动作、组数、次数、建议重量、组间休息都排好了。做完一个动作就点它左边的圆圈 ✓。
身体数据可以不填 —— 只影响营养建议，不影响计划生成。
🧭 底部五个按钮
📋
计划　生成计划、今天练什么、打卡、记成绩、周期进度。
📚
动作库　搜动作看示范 GIF；1RM / 热身组 / 杠铃片 / 饮食四个计算器。
📊
进度　打卡热力图、部位分布、动作趋势、个人纪录、减载建议。
💊
补给　常见运动补剂怎么吃、注意什么。
💝
发电　赞赏开发者 + 数据管理（导出 / 导入 / 恢复码 / 重置）。
📋 计划页：每个东西都是什么意思
🎯
今日训练卡　页首那块：今天该练哪天的内容、还剩几个动作没做、连续打卡几天。点它直接跳到今天。
📈
周信息条　当前第几周、这周是什么周（基础 / 爬坡 / 挑战 / 减载），以及本周处方：是「本周加 1 档重量」还是「本周重量不变，每组加到 N 次」。照这句练就行。
🔢
动作行　格式是「4 组 × 9-12 次」，下面一行是强度和 RPE 建议，右边 ⏱ 按钮点一下开始组间休息倒计时。
⚖️
重量 / 次数 / RPE 三个框　力量动作下面自带。已经预填上次的数字，一样的就不用动；不一样就改一下，改完自动存。
🔄
替换　动作名右边的小箭头，换个同肌群、同器械的替代动作。
💬
训练笔记　每天最下面一个输入框，写感觉、身体反应，自动保存。
📅
周切换　顶部一排周数，可以回看已练过的周。未来的周是锁着的，防止剧透也防止乱跳。
RPE 怎么打分？
1–10 分，主观费力程度。做完还剩 4 次力气 ≈ 6 分；还剩 2 次 ≈ 8 分；一次都做不动了 = 10 分。 这是整个 App 调节重量的唯一依据 —— 打高分（吃力）它就给你减，打低分（轻松）它就给你加。
⚠️ 别客气，也别硬撑。RPE 打低了，它下一周给你的重量会超出你真实能力，几周后就会练不动。
🔬 它在替你做的两件专业的事
📈
周期化　计划不是每周一样：几周爬坡 → 一周减载（重量和组数一起降）→ 再进入下一轮。这是防止练到瓶颈和受伤的标准做法，你不用自己算。
😴
减载周不用慌　看到重量掉了、组数少了是故意的。减载周的成绩不记入进步基准，下周会直接回到减载前的重量。
🎯
下次练多重是算出来的　在进度页和动作行附近会告诉你目标重量和原因（上次 RPE + 本周周期 + 上次完成次数）。第一次练某个动作时不显示 —— 没有历史就不瞎猜。
⚖️
部位平衡　练满两周后，进度页会提示某个部位练太多或太少（比如只练胸不练背）。
📚 动作库
🔍
搜索 + 筛选　按部位（腿/胸/背/肩/臂/核心/有氧/康复）、难度、器械三排筛选。点动作名看示范 GIF 和要点。
🧮
四个计算器　1RM（用你举起的重量和次数估算极限，还能跟个人纪录对比）、热身组、杠铃片（该挂几片）、饮食（蛋白/碳水吃多少克）。
➕
添加自定义动作　列表最下面，自己加动作进计划。
📊 进度页：练了几周后看这里
🔥
训练热力图　最近 90 天哪天练了，一眼看到自己有没有断。
📊
本周进度 / 频次趋势 / 热量趋势　这周练了几天、跟之前比是多了还是少了。
📈
动作趋势　你常练的动作，重量/次数是不是在往上走。
🏆
个人纪录（PR）+ 成就徽章　破纪录会弹提示；连续打卡、累计次数解锁徽章。
🩺
减载决策 / 疲劳预警　它会根据你最近的记录判断「该不该减载」「某个部位是不是练过头了」。可以手动开启减载周。
📅
月度复盘　一个月下来练了多少、哪儿进步了、哪儿卡住。
🗓
周期卡　整轮周期的强度和组数安排，可以手动微调。
💾 数据在你自己手里（也只在你手里）
📱
存在本机　所有记录都保存在这台手机的浏览器里，不上传服务器、不需要注册。
⚠️
所以：清缓存 / 换手机 / 换浏览器 = 数据没了　建议定期备份。
📤
导出数据　「💝 发电」页 → 导出，得到一个 JSON 文件。
📥
导入数据　新设备上打开 FitBuddy → 导入 → 选那个 JSON。
🧩
恢复码　导出一串字符，换设备时粘贴回去。适合不方便传文件的场景。
🔄
重置　清空所有数据重新来（不可撤销，先导出）。
💡 几个容易忽略的
📲
装到桌面当 App 用　浏览器菜单里「添加到主屏幕」，之后全屏运行、离线也能打开。
🔔
每日训练提醒　「🎯 手动调参数」里面最下面，开关 + 设定时间，需要允许通知权限。
⏱
右下角悬浮的 ⏱　随时手动开一个组间休息倒计时，可以开语音播报。
🏥
伤病限制　膝盖/腰/肩/手腕/脚踝不适可以勾选，计划会自动避开相关动作（动作上标 ⚠️ 表示已跳过）。
🌙
深色 / 浅色　右上角按钮切换。
❓ 常见问题
为什么第一次练某个动作不给我建议重量？

因为它只根据你的上次实际成绩推算，没有历史就不瞎编。练一次、填上重量次数，下次就有目标了。

为什么这周的重量比上周轻了？

大概率是减载周（周信息条会写明）。这是计划的一部分，下周自动回到减载前的重量。

动作行说「每组加到 N 次」，但我上次做了更多，怎么办？

那是本周的下限。你做得到更多就照你自己的做，把真实次数填进框里就行。

打卡是按「组」还是按「动作」？

点一次圆圈 = 这个动作整项完成，系统按计划给你的组数记账（比如 4 组的深蹲记 4 组），不用一组一组点。

可以两个人用一台手机吗？

不建议 —— 数据是本机的，两人会混在一起。一人一台设备，用导出/导入各存各的文件。
